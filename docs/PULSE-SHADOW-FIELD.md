# Pulse recovery field trial (Time 2)
Use a retail Time 2, the signed pulse-shadow Android build, and both the firmware and PBW named below. Keep the production alarm configuration and the raw-quality gate setting fixed; write down its setting, device versions and strap fit. The experiment observes ordinary hunts; **sensor lab mode holds the detectors**, so leave it off.

1. On the Android phone install the pulse-shadow companion APK over Standby. With the Time 2 booted normally, install the matching v4.46.0-5-g115381203 PBZ via the Pebble app. Try slot 0 first; only use slot 1 if Pebble says the slot does not match. Do not sideload from the recovery screen. Verify the version on the watch. Install the Standby 0.5.16 pulse-shadow PBW and open it once. Check that normal minute reports arrive and use the agreed test-alert drill to confirm delivery to a test contact.
2. While awake, record clock times for ten minutes each at normal fit, loose but comfortable fit, then normal fit again. For off-body labels, note the moment you remove it and place it on the desk, then repeat with the sensor facing the lit wall. Include a deliberate put-on after each off-body period. Do not simulate loss of circulation. Expect ordinary motion to terminate some hunts. Dismiss prompts normally; arrange any intentional contact-alert drills with responders first.
3. Wear normally for at least three nights; note prompts, actual wearing/removal times, charging, phone disconnects and waking. Do not label an entire night as motionless or infer continuous good sensor contact. Repeat desk conditions on separate days if few hunts occur. Record approximate charging interval, daily battery use and worker heap from ordinary minute reports.
4. On the Android phone use Standby’s Share logs. Look for PulseShadow records. start is watch epoch; t, live and two are seconds relative to hunt start. 65535 means unobserved. event=0 start, 1 observation/live decision, 2 deadline, 3 interruption, 4 replacement/shutdown. purpose=0 pulse loss, 4 not-worn. off is the sensor flag, not ground truth. available=false means no usable diagnostic snapshot. Confirm available=true with advancing seq before interpreting a run. If no hunts occurred, that period contains no comparisons.
5. Group by start and purpose, remove identical PK2 replays, and flag missing starts/ends, resets, sequence gaps, interruptions and clock changes. Compare first live and two times with labels. Report worn and off-body hunt counts separately, counts accepting recovery under each rule, paired delay (two minus live), prompt counts and missing follow-up. After live ends a burst, observations are normally sparse: a missing second reading is censored, not a prevented false recovery or a predicted extra prompt. Use only comparable observed samples to discuss differences. If all apparent gains are censored, the result is inconclusive.
6. Stop if the worker restarts, memory becomes unusually low, minute reports disappear, or normal alarm delivery changes. Restore the prior Standby PBW; for a full rollback use the matching prior v4.46.0-4-g0659dc817 firmware slot. Keep the newer companion if Android rejects an APK downgrade. No detector change follows automatically from this trial.
